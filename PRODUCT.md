# Productivity Vault

Personal, browser-local productivity PWA. Frequent daily use, primarily on a phone with one hand; desktop remains dense and efficient. Today gives habits, tasks, projects, and goals equal prominence.

Next.js static export, React, TypeScript, Dexie/IndexedDB, Workbox, Vercel. No accounts, backend, sync, external fonts, or runtime API credentials. Keep the production origin stable.

Preserve all existing records, schema v3, stable IDs, calculations, recurrence, recovery snapshots, backup v2 export and v1/v2 import. Preserve hash routes, offline editing, safe areas, installation, and explicit updates after pending writes.

Daily check-offs, daily/weekly quantity habits, editable dated history and streaks; tasks with priorities, notes, subtasks, project links, daily display and weekly recurrence; projects; manual and linked goals; calendar; reports; settings, backups and recovery are all in scope.

Approved direction: compact, calm, readable, minimal. Adapt phone density for comfortable touch; keep desktop rows dense. No motivational or decorative copy. User-approved implementation plan is the contract.
